# Errata

Corrections to released editions that change no meaning: a typo, a broken link, or a clearer sentence. The edition's own text is not edited; its corrections are listed here, numbered per edition (`SPEC-01P.1 E1`, `SPEC-01P.1 E2`), and in the notes of the release that lists them. A correction that changes meaning is a new edition, not an erratum.

Each entry gives the erratum's name, the section and clause, the text as published, the corrected text, and the release that lists it.
